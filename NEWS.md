# openetR 0.0.0.9000

* Documentation now includes native Quarto articles, a clearer quick start,
  and links between package functions and common OpenET workflows.

* Errors now use 'cli' formatting with clearer argument names and actionable
  guidance.

* `openet_metadata()`, `openet_point_timeseries()`, and
  `openet_polygon_timeseries()` now validate collection options locally before
  submitting a request.

* `openet_api_key()`, `openet_metadata()`, `openet_point_timeseries()`, and
  `openet_polygon_timeseries()` provide authenticated access to core OpenET
  raster endpoints.
